カメラ画面のシャッターの上で左右に動かして選ぶ。既定のフォルダ「—」と、その中に作ったフォルダに保存する。

保存先を増やすには、Apps Script を新しい gas/Code.js に更新してデプロイし直す。更新するまでは既定のフォルダに保存する。

 —既定 保存先を足す 帯に出していない保存先
未送信の枚数を通知に出す Apps Script の立て方
  1. 新しい Apps Script を作り、gas/Code.js の中身を貼る
  2. 関数 setup を実行して Drive の権限を許可する。実行ログにキーが出る
  3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。実行するユーザーは「自分」、アクセスできるユーザーは「全員」
  4. 出てきた /exec の URL の末尾に ?k=<キー> を付けて、上の欄に入れる

既定の保存先はマイドライブの receipts フォルダ。アプリで足した保存先は、その中のフォルダになる。別のフォルダを既定にするときは、スクリプトのプロパティ FOLDER_ID にフォルダの ID を入れる。
